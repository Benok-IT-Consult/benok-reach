# Benok Reach

**Benok Reach** is Benok IT Consult's branded remote-support app. It is built from
[RustDesk](https://github.com/rustdesk/rustdesk) 1.5.3 (copyright © Purslane Tech Pte. Ltd.), which is licensed under the
**GNU Affero General Public License v3.0** (see `LICENCE`). Benok Reach is distributed under the same licence, and this
repository is its complete corresponding source.

Download: https://remote.benokitconsult.com

## What differs from RustDesk

| Area | Change | Where |
|---|---|---|
| Server | Built in and locked: ID server `remote.benokitconsult.com` (Benok's own RustDesk server) and its public key; relay comes from that server | `libs/hbb_common/src/config.rs` (submodule fork `Benok-IT-Consult/benok-reach-hbb-common`, branch `benok-reach`) |
| Locked settings | ID/relay server and WebSocket settings hidden; RustDesk account sign-in off; no device registration with admin.rustdesk.com | same file (`OVERWRITE_SETTINGS`, `HARD_SETTINGS`, `BUILTIN_SETTINGS`) |
| Name | Internal name `BenokReach` (used for the Windows service, install folder, executable); shown as "Benok Reach" | `config.rs`, `src/common.rs` (`get_app_display_name`), `flutter/lib/common.dart` (`appName`), `flutter/windows/runner/main.cpp` |
| Updates | RustDesk's update check is off (it is off for every build not named RustDesk) | `src/common.rs` (`is_custom_client`) |
| Windows file details | Product "Benok Reach", company Benok IT Consult Ltd. | `Cargo.toml` (winres), `flutter/windows/runner/Runner.rc` |
| Android | Application ID `com.benok.reach` (installs next to RustDesk), label "Benok Reach" | `flutter/android/app/build.gradle`, `AndroidManifest.xml`, `res/values/strings.xml` |
| Icons and logo | Benok "b" mark; "Benok Reach" wordmark | generated by `benok/make-icons.ps1` |
| Build | Only Windows x64 (self-extracting `BenokReach-<version>-x86_64.exe`) and Android APKs; output names `BenokReach-*` | `.github/workflows/flutter-build.yml`, `.github/workflows/benok-reach.yml` |

## Building

Actions tab → **Benok Reach build** → Run workflow. The release `benok-reach-<version>` gets the Windows exe and the
signed Android APKs. Android signing uses the repository secrets `ANDROID_SIGNING_KEY`, `ANDROID_ALIAS`,
`ANDROID_KEY_STORE_PASSWORD` and `ANDROID_KEY_PASSWORD` (the Benok Reach key; keep its backup safe).
